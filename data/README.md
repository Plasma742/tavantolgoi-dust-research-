# Data directory

This repository intentionally contains **no satellite rasters, measured PM10 values, proprietary mine boundaries, or generated predictions**.

- `roi/` — authoritative approved polygons, if licensing and publication permissions permit; otherwise record provenance and keep them in a secure private store.
- `raw/` and `exports/` — local/generated files, ignored by Git.
- Always record coordinate reference system, geometric accuracy, source, acquisition date, permitted use and geometry changes.
- Never infer an actual Tavan Tolgoi pit or site boundary from a casual text location.
